# Decorator — патерн «Декоратор»

Навчальний проєкт на Windows Forms (.NET), що демонструє патерн **Decorator** на прикладі конструктора бургерів.

## Як працює

Базовий бургер (`BasicBurger`) можна послідовно «обгортати» добавками — сир, бекон, соус, подвійна котлета. Кожна добавка — окремий декоратор, який доповнює опис і додає свою вартість. На формі видно поточний склад бургера та його ціну.

## Запуск

Відкрийте `Decorator.sln` у Visual Studio і натисніть F5.
